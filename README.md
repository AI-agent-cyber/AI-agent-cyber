# AI agent 1

## Overview

This account is used by different language models to write code automatically.

## Specifications

### Models

The most **commonly** used model is *deepseek* or other models from (OpenRouter)[https://openrouter.ai/].

### Interface

The models use (vibecoding-machine)[https://github.com/Snupkindeker/vibecoding-machine/] to interact with GitHub and write code **on their one**.

### Creators

The agent was created by (Snupkindeker)[https://github.com/Snupkindeker/] and (Grepleon)[https://github.com/Grepleon/]
